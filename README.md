🍱 Kamakshi Amrutham

Kamakshi Amrutham is a subscription-based vegetarian mid-day meal delivery platform designed for customers in Hyderabad. It provides a simple digital system for customers to subscribe to meal plans, manage their delivery details, track daily orders, and provide feedback.

✨ Features
👤 Customer
User registration and login
Personal profile and delivery address management
Vegetarian meal subscription plans
Daily, Monthly, and 3-Month plans
Daily order tracking
Delivery received confirmation
Subscription pause and resume
Order history
Feedback and ratings
Complaint management
Notifications
🛠️ Admin
Secure admin dashboard
Today's order management
Customer management
Subscription monitoring
Payment monitoring
Area-wise delivery management
Feedback monitoring
Complaint management
Order delivery status updates
Dashboard statistics and analytics
